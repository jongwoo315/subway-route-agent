# #190 설계 — 도구를 잘게 줄 때와 크게 묶어 줄 때를 비교한다

## 무엇을 바꾸나

지금 LLM + 도구(`llm-tools`)는 도구 셋 하나만 받는다(`src/subway_route_agent/tools.py` `TOOLS` — `find_station`·`line_stations`·`travel_seconds`).
이 티켓은 도구 구성을 둘로 나눠 같은 질문 셋에 답하게 하고, 비교 리포트에 지표를 나란히 놓는다.

- 흐름은 이미 있다(#185~#189). 바꾸는 stub: 도구 구성이 하나뿐인 것
- 그대로 두는 것: 질문 셋, 채점, 정답, LLM 혼자

## 착수 때 본 사실 (2026-11-14, main `b11c987`)

- 지금 도구 셋에는 환승 시간을 알려 주는 도구가 없다. 정답 그래프는 #189부터 데이터 환승 시간을 쓴다. `TOOLS_SYSTEM`은 「환승 시간은 역과 호선마다 다르다」만 말한다
- #189 설계가 「도구 `transfer_seconds` 추가」를 C안으로 적고, 도구 셋을 바꾸는 일이 #190과 겹친다며 미뤘다
- #189 실제 키 실행: LLM + 도구 3/10·4/10(도구 호출 합 52, 응답 시간 합 95.2초, `reports/compare.md`). 이번 티켓의 직전 값이다. 다만 잘게 나눈 구성이 도구 하나를 더 받으면(아래 A안) 같은 조건이 아니다
- 비교 리포트 머리 줄에 정답률·도구 호출 합·응답 시간 합·토큰은 있고, 지어낸 역 수·지어낸 소요 시간 수·질문당 도구 호출은 없다(`src/subway_route_agent/report.py:126` `render_compare`)
- 같은 구성을 여러 번 돌리는 옵션이 없다. #189는 명령을 두 번 쳐서 두 번 쟀다

## 두 구성이 줄 수 있는 정보를 맞춘다

비교하려는 것은 **묶는 방식**이다. 한쪽만 아는 정보가 있으면 차이가 묶는 방식 때문인지 정보 때문인지 못 가린다. 그래서 두 구성 모두 「어떤 경로든 그 경로의 전체 소요 시간(환승 포함)」을 알아낼 수 있게 맞춘다.

- 잘게 나눈 쪽: 한 호선 구간 시간(`travel_seconds`)과 환승 시간(`transfer_seconds`)을 따로 불러 직접 더한다
- 크게 묶은 쪽: 경로를 통째로 넘기면 전체 소요 시간을 한 번에 받는다(`route_seconds`)

맞추지 못한 것이 하나 남는다. 크게 묶은 쪽은 한 호선의 역 목록을 볼 수 없다. 묶음이 「고른 경로 하나를 재는 일」에 맞춰져 있어서다. 그래서 크게 묶은 쪽은 역과 호선을 LLM이 아는 지식으로 고르고, 틀리면 오류 메시지(그 역이 지나는 호선, 이름이 비슷한 역 후보)로 고친다. 이 차이는 리포트 머리에 적는다.

## 티켓의 실패 징후 — 크게 묶은 도구가 정답 경로를 돌려주면 안 된다

`route_seconds`는 경로를 받기만 하고 경로를 돌려주지 않는다. 돌려주는 것은 그 경로의 소요 시간·환승 수, 또는 오류다. 다른 경로를 제안하지 않는다. 테스트가 출력 키를 고정한다.

`route_seconds`가 재는 방법은 채점이 답 경로를 재는 방법과 같다(`fill_path` → `path_seconds`). LLM은 자기가 고른 경로가 몇 초인지 채점과 같은 값으로 미리 안다. 그 경로가 가장 빠른지는 모른다 — 다른 경로를 직접 골라 다시 재야 한다.

### 도구 정의 (A안 기준)

- `transfer_seconds(station, from_line, to_line)` → `{"seconds": N}`. 그래프의 갈아타는 간선 가중치를 그대로 돌려준다(그 방향 → 반대 방향 → 180초, `graph.build_graph`). 갈아타는 역이 아니거나 그 호선이 없으면 `{"error": …}`
- `route_seconds(path)` — `path`는 `SCHEMA`의 path와 같은 `[{station, line}]`. 중간 역은 빼도 된다(채점과 같이 채운다). 출력:
  - 성공: `{"seconds": N, "transfers": K}`
  - 데이터에 없는 역: `{"error": "…", "candidates": [이름이 비슷한 역 최대 10개]}`
  - 그 호선에 없는 역: `{"error": "…", "lines": [그 역이 지나는 호선]}`
  - 이을 수 없음: `{"error": "i번째와 i+1번째를 이을 수 없다"}`
