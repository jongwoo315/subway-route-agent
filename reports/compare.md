# 비교 리포트

- 데이터: seoul_metro_1to8_240810.csv (서울 열린데이터광장 OA-12034, 2024-08-10 기준, 1~8호선)
- 환승 시간: 서울교통공사 환승역 거리·소요시간 (data.go.kr 15044419, 2026-08-31 기준, 최단 환승거리 ÷ 초당 1.2m)
- 데이터 환승 시간을 쓴 환승역 35개 · 180초가 남은 환승역 0개 (갈아타는 방향 78개 중 반대 방향 값 1개). 기다리는 시간은 0으로 본다
- LLM + 도구 지시문에만 도구 안내 한 문장과 「환승 시간은 역과 호선마다 다르다. 경로는 직접 고른다」 문장이 있다
- llm-tools-search 지시문에는 「경로는 직접 고른다」가 없다. 도구가 가장 빠른 경로를 고르기 때문이다
- 도구 구성: llm-tools = find_station, line_stations, travel_seconds, transfer_seconds / llm-tools-coarse = route_seconds / llm-tools-search = find_station, shortest_route. 지시문은 도구 안내 문장이 구성마다 다르다
- 크게 묶은 도구는 한 호선의 역 목록을 볼 수 없다
- 경로 탐색 도구는 정답과 같은 다익스트라(`route.shortest`)를 부른다
- 같은 질문 10개를 답하는 쪽마다 5번 돌렸다. 범위는 지표마다 회차 중 최저~최고다
- llm-tools (모델 gpt-5.4-mini)
- llm-tools-coarse (모델 gpt-5.4-mini)
- llm-tools-search (모델 gpt-5.4-mini)
