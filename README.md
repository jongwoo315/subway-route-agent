# subway-route-agent

서울 지하철 길찾기 질문을 LLM에게 맡겼을 때, 도구를 주면 무엇이 좋아지고 무엇이 비싸지는지 숫자로 잰다.

- 질문 예: 「강남에서 홍대까지, 환승 한 번 이하로, 9시 전에」
- 채점: 다익스트라가 계산한 최단 경로와 그대로 비교한다. 사람 판단이 끼지 않는다
- 비교 대상: 다익스트라(정답) · LLM 혼자 · LLM + 도구(역 검색, 노선 조회, 두 역 사이 소요 시간)
- 재는 것: 지어낸 역·소요 시간 수, 조건을 어긴 수, 질문 하나당 도구 호출 수와 응답 시간

## 데이터

- 출처: 서울 열린데이터광장 OA-12034 「서울교통공사 역간거리 및 소요시간」, 2024-08-10 기준
- 이용 조건: 공공누리 1유형(출처 표시, 변경 가능)
- 범위: 서울교통공사가 운영하는 1~8호선만 있다. 9호선과 1호선 코레일 구간은 없다
- 소요시간은 표준 운행시간이다. 실시간 시각표와 환승 시간은 없다
- 파일: `data/seoul_metro_1to8_240810.csv`. 받은 CSV를 UTF-8로 바꿔 커밋했다. 실행할 때 네트워크는 필요 없다
